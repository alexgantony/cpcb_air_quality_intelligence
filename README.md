### India Air Quality Intelligence Dashboard

A Power BI analytics project using **Central Pollution Control Board (CPCB) air-quality data from the Government of India's Open Government Data platform**.

The project cleans and transforms the raw dataset using **Python/Pandas**, then builds an interactive Power BI dashboard to analyse air quality across India by **state, city, monitoring station, AQI and individual pollutants**.

The dashboard will provide a bird's-eye view of India's air quality along with location-level and pollutant-level analysis, data-quality indicators, and interactive filtering.

The project will later evolve into a live analytics system:

```text
V1 → Government CSV → Python → Power BI Dashboard
V2 → CPCB API → Python → Historical Storage → Power BI
V3 → Cloud Pipeline → Automated Refresh → Power BI
V4 → FastAPI → Live Refresh → Automated Air Quality Reports
```

**Primary goal:** demonstrate practical skills in **Python, Pandas, data cleaning, Power BI, Power Query, DAX, data modelling, and data visualization** through a real government dataset.
